# FolderPilot 中文使用说明

## 启动

下载 `FolderPilot.exe`，放在任意可读取位置后双击。无需 Python。应用数据默认保存在 `%LOCALAPPDATA%\FolderPilot`，隔离存储为其 `vault` 子目录，任务为 `tasks` 子目录。也可使用 `FolderPilot.exe --data-dir "其他独立数据目录"` 指定数据位置。不要将应用数据放入待处理目录内部。

## 差异检测

1. 选择“差异检测”，设置主目录与副目录。
2. 默认精确模式按相对路径确定对应项，内容通过大小和 SHA-256 判断。修改时间不同但内容相同仍为未变化。
3. 快速模式比较大小和修改时间，仅用于初步判断，不能证明内容相同。
4. 点击扫描，使用分类筛选；双击行查看完整路径和原因。可导出 UTF-8 CSV 报告。
5. “移动/重命名线索”只提示相同内容的新旧路径，程序不会自动重命名。

## 文件夹同步

默认“安全补全”复制源端新增文件、保存目标旧版本后更新内容不同的文件、保留目标独有文件和目录。

“镜像同步”将目标独有文件移入隔离区，并移除目标独有空目录（记录恢复信息）。需要主动选择镜像，并在完整预览后再次明确确认。跳过冲突时，内容不同的同路径文件会保留目标版本，因此不会得到严格镜像。

同步始终递归扫描全部文件。扫描与执行前校验均在后台进行；执行计划强制使用精确指纹。执行前检查到任一范围内变化，需重新扫描和确认。

## 规则清理

主目录作为参考，副目录作为待处理。可选择完整文件名、文件名主体、相对路径、相对路径忽略扩展名四种规则。

例如参考 `报告.docx` 与目标 `报告.pdf` 在“文件名主体”规则下匹配成功，即使文件内容完全不同，也不会清理该目标文件。

扩展名用逗号分隔，如 `.jpg,.nef`、`txt,csv`。过滤条件同时作用于两端；留空扫描全部文件。取消递归后只处理当前层文件，子目录文件不处理。区分大小写按字符规则匹配；Windows 相对路径大小写冲突会阻止执行。

重复名称或多对一关系会阻止清理，并列出歧义键及路径。改用相对路径规则或缩小选择范围后重新扫描。参考目录为空（含过滤后为空）、扫描访问失败、链接或异常路径均禁止清理。清理只隔离文件，不清理目录。

## 预览、执行和取消

先选择两个文件夹，再点击“3. 查看待同步内容”或“3. 查找多余文件”。核对结果后点击“确认同步…”或“确认清理…”，在完整预览中确认执行。

完整计划列出复制、更新、跳过、隔离和目录操作，包括完整路径、原因及总数。无确认不会修改业务文件。安全补全保留目标独有文件；镜像同步会将它们移入隔离区。

正在执行时可点击取消；程序在安全边界停止后续步骤，保留已完成记录。窗口关闭时会询问是否取消并等待安全退出。失败会立即停止后续操作，准确报告成功、跳过和失败数量，不自动回滚已完成步骤。

## 隔离与恢复

- “隔离与恢复”按路径、状态或任务 ID 筛选，选择单条记录恢复。
- 恢复前校验隔离副本。原路径被占用时，需要额外确认；当前文件先保存另一个隔离副本。
- 恢复后隔离副本仍保留。删除业务文件、更新文件和恢复覆盖均经过统一执行引擎。
- 永久删除单独发起，需要先确认预览，再输入“永久删除”。不会自动清空隔离区。
- 隔离始终采用复制、校验、再移除源文件流程，同卷/跨卷一致。复制失败时保留原文件。
- `preparing` 记录表示任务未完成，可能没有完整副本；不能据此认为原文件已清理。

## 中断任务核查

异常退出可能留下 `running` 任务、`preparing` 隔离记录或 `.folderpilot-tmp-*` 副本。程序不自动重放这些步骤，并阻止进一步批量执行。

1. 在“隔离与恢复”查看任务 ID、原路径和隔离路径。
2. 在“日志与设置”查看该任务的步骤，核对业务目录、隔离对象和临时副本的实际内容。
3. 先保全可用文件。临时副本需人工核查及处理；程序不会自动删除崩溃遗留副本。
4. 确认核查完成后，点击“核查中断任务”解除任务级阻止，再重新扫描生成新计划。

这是故障识别机制，不是完整事务回滚或灾难备份。请另行维护重要数据备份，不要与其他程序同时修改业务目录，也不要用不同隔离数据目录同时操作同一批文件。

## 任务与日志

任务管理可以保存当前配置、加载、修改所选任务、导入和导出版本 1 JSON。加载不会自动执行；修改路径或设置会使旧计划失效。

日志与设置记录扫描数量、文件完整路径、操作类型、错误和取消。日志包含本机路径，请留意导出和分享的范围。界面显示最近 2000 条日志，可导出最多 100 万条日志；更完整记录保存在 SQLite 数据库中。

## 支持边界

首版支持 Windows x64 本地普通文件/目录。保留文件字节内容、普通时间戳及基础 `copystat` 元数据；不承诺 NTFS ACL、备用数据流、所有者等全部属性。禁止目录相同、嵌套、磁盘根目录、符号链接/联接点及文件目录类型冲突。

程序没有抵御恶意进程在最后一次校验与替换之间抢占路径的能力，也不能保证存储设备在突然断电时完整落盘。真实跨磁盘设备故障、网络共享及所有 Windows 版本未逐一验证。
