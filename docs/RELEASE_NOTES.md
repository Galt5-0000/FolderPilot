# FolderPilot v0.1.0

通用文件夹差异检测与安全管理工具，简体中文 Windows 桌面界面。

- “选文件夹 → 扫描 → 确认”三步引导，同步页一句话解释安全补全与镜像区别。
- Windows 每显示器 DPI 适配，修正字体设置，按缩放调整窗口和表格。
- 差异检测：相对路径对应、精确 SHA-256 与快速元数据模式、目录/空目录差异、可能移动线索。
- 安全补全默认保留目标独有文件；镜像模式在额外确认后隔离多余文件。
- 按文件名、文件名主体、相对路径或忽略扩展名的相对路径清理；匹配不依赖内容相同。
- 覆盖前保存旧版，隔离复制后校验；恢复占用路径需明确确认并保留被覆盖版本。
- 任务保存与导入导出、后台扫描和取消、SQLite 日志、未完成任务阻止自动重放。

## 下载与验证

Windows x64 用户下载 `FolderPilot.exe` 后双击运行，无需安装 Python。
`SHA256SUMS.txt` 提供 SHA-256；`build-info.json` 提供实际构建与 EXE 自检结果。
中文说明见 `USER_GUIDE.md`；自动化结果见 `test-results.xml`。

## 已知限制

- EXE 未做代码签名，首次运行可能显示 Windows 信誉提示。
- 以 Windows 本地普通文件和目录为支持范围；不承诺保留 ACL、所有者、备用数据流、加密属性、稀疏/压缩属性或硬链接关系。
- 不跟随符号链接和联接点；文件/目录类型冲突、大小写路径碰撞、规则匹配歧义需人工解决。
- 不自动重命名、不双向合并、不自动重放崩溃任务，不提供完整事务回滚。
- 隔离区不是完整备份。程序或系统崩溃后需人工核查日志、隔离对象、临时副本与实际路径，再重新扫描。
- 进度按文件/步骤更新，大文件哈希可取消；大目录报告可能占用较多内存。
- 未验证真实跨卷设备故障、断电、网络共享、恶意并发修改及所有 Windows 版本。
