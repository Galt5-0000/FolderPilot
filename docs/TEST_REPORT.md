## 限制与如实说明

- 权限不足、磁盘不足、损坏、符号链接分支及复制失败的部分场景通过故障注入验证，不代表已对真实设备故障或所有 NTFS 权限组合进行实测。
- 100% 和 200% 的控件适配通过模拟窗口 DPI 验证；本机实际显示缩放为 150%。未人工测试所有多显示器移动组合及显示器硬件。
- Windows 窗口检查在用户按 Escape 后停止；未继续人工操作全部界面。关键交互以 Tk 自动化和实际 EXE 自检验证。
- 未测试真实断电、真实跨磁盘设备故障、网络共享、恶意路径抢占、NTFS 备用流或全部 Windows 版本。
- 隔离区不是完整备份系统；中断后不自动重放，也没有完整事务回滚。
